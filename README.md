# WriteSphere ✍️

A modern, responsive landing page designed for content creators, bloggers, and storytellers. Built with clean HTML5 semantic markup, modern CSS styling featuring a Neo-Brutalist aesthetic, and smooth, scroll-triggered animations powered by GSAP.

---

## ⚡ Features

* **Scroll-Triggered Micro-Interactions**: Smooth entrance and stagger transitions driven by GSAP and ScrollTrigger.
* **Modern Aesthetic**: Clean Neo-Brutalist visual accents, custom badges, high-contrast typography, and solid dropshadow depth.
* **Fully Responsive Design**: Adaptive multi-column grid that shifts smoothly across mobile, tablet, and desktop viewports.
* **Comprehensive Sections**:
  * Hero showcase with dynamic call-to-action
  * Category overview cards
  * Step-by-step onboarding walkthrough
  * Reader & writer testimonials
  * Interactive contact form and footer newsletter integration

---

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Markup** | HTML5 Semantic Architecture |
| **Styling** | Custom CSS3 (CSS Grid, Flexbox, Responsive Clamping) |
| **Animations** | GSAP 3 & GSAP ScrollTrigger |
| **Typography** | Space Grotesk (Google Fonts) |
| **Icons** | Remix Icon & Simple Icons CDN |
